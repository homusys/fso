# Full Stack Open

This repository contains my exercises and projects from the [Full Stack Open](https://fullstackopen.com/en/) course by the University of Helsinki.

The course focuses on modern web development, covering frontend, backend, databases, and other technologies used to build full-stack applications.

## Technologies

Technologies covered throughout the course include:

- JavaScript
- React
- Node.js
- Express
- REST APIs
- MongoDB
- TypeScript
- GraphQL
- Testing
- CI/CD

_Technologies listed may vary depending on the exercises and course parts completed._

## Goals

- Practice full-stack web development.
- Strengthen my understanding of React and JavaScript.
- Learn backend development and API design.
- Gain experience working with databases, testing, and deployment.
- Build practical projects while progressing through the course.
